# spec-16-9 육안 확인 증거 (2026-08-10, 사람 세션)

[[DW-764]]가 지적한 공백을 메운다 — 16.9는 시각 4축을 **위젯 테스트만으로** 닫았고,
스펙이 처방한 "육안 확인 또는 대장 등재"가 실행되지 않았다. 여기서 실제 기기로 확인한다.

기기: SM-G991N (`192.168.219.103:36959`, 무선 디버깅), prod 백엔드 debug APK,
`pm clear`로 **로그아웃 상태**에서 촬영. 커밋 `e5c9047`(final_revision `555962b`) 빌드.

**이 촬영이 보지 못한 것**(추측 아니라 조건상 불가):
- **신뢰속성 행**은 로그아웃 상태라 화면에 없다 — anon 조회는 그 3컬럼을 애초에 select하지 않는다(`806b3a6`).
  카드 안 위치(사진 아래 전용 행)는 위젯 테스트로만 확인된 상태이고, **로그인 상태 육안 확인은 남아 있다**.
- 다크모드·작은 화면(<390px)·긴 차량명 오버플로는 이 촬영 범위 밖이다.
